# Keiba-theory

競馬理論の分析メモを作成するための、日本語UIのシンプルなWebアプリです。  
最小版として、HTML/CSS/JavaScriptだけで動作し、入力データはブラウザ内のローカルストレージに保存します。

## 機能

- 日付、競馬場、レース番号、レース名、出走頭数の入力
- コンピ順位1位〜10位の馬番・馬名とコンピ指数の入力
- 朝イチ単勝順位、朝イチ複勝順位、調教評価の入力
- 出走頭数×コンピ順位の基準値表を使った階級指数の自動計算
- コンピ指数、朝イチオッズ、調教データだけを使った合計点の自動計算
- 合計点から軸候補・相手候補を自動判定
- 11位以下のイレギュラー馬メモ
- 軸候補、相手候補、買い目メモの入力と保存済みメモ表示
- スマホ・タブレットで見やすい縦長レイアウト
- ブラウザ内保存（localStorage）

## 階級指数

```text
階級指数 = コンピ指数値 - 基準値
```

基準値は `docs/kaikyuu-index.md` の「階級分け基準値」を使います。  
プラス幅が大きいほど、そのコンピ順位帯ではお買い得度が高い馬として扱います。

## 合計点の考え方

第一段階では、次の材料だけで合計点を出します。

```text
合計点 = コンピ順位点 + 階級指数点 + 朝イチ異常点 + 調教点 + 組み合わせボーナス
```

- コンピ順位点：コンピ上位ほど基礎点を高くする
- 階級指数点：コンピ指数が基準値をどれだけ上回るかを見る
- 朝イチ異常点：単勝順位・複勝順位がコンピ順位より高い馬を加点する
- 調教点：SS/S/A+/A/B+/B/C/D、または◎○△×で加点する
- 組み合わせボーナス：階級指数プラス、朝イチ異常、調教評価が重なる馬を強く加点する

判定の目安：50点以上=軸最有力、42点以上=軸候補、32点以上=相手本線、24点以上=相手候補、16点以上=押さえ。

## 11位以下の扱い

コンピ11位以下は、基本的に通常の軸・相手候補には入れません。  
ほぼ来ないゾーンとして、通常判定とは分けて「イレギュラー馬メモ」で管理します。

例外として見る材料は次のようなものです。

- 調教が良すぎる
- 初ブリンカーなどの強い変化材料がある
- 朝イチ単勝・複勝がコンピ順位に対して異常に売れている

ただし、特にテクニカル6のP1・P2寄りでは、基本はケン。買う場合でも、3連複ではなく単複のみを基本にします。

## 使い方

1. `index.html` をブラウザで開きます。
2. レース情報、出走頭数、コンピ順位、コンピ指数を入力します。
3. 朝イチ単勝順位、朝イチ複勝順位、調教評価を入力します。
4. 階級指数、合計点、軸候補、相手候補が自動で表示されます。
5. 11位以下にどうしても臭い馬がいる場合は、イレギュラー馬メモに手書きします。
6. 必要に応じて、最終的な軸候補メモ・相手候補メモ・買い目メモを入力します。
7. 「保存する」を押すと、ブラウザ内にデータが保存され、右下または下部の「保存済みメモ」に反映されます。
8. 「入力をクリア」を押すと、画面上の入力欄だけを空にできます。保存済みデータは削除されません。
9. 「保存データ削除」を押すと、ブラウザ内に保存されたデータも削除されます。
