# Keiba-theory

競馬理論の分析メモを作成するための、日本語UIのシンプルなWebアプリです。  
最小版として、HTML/CSS/JavaScriptだけで動作し、入力データはブラウザ内のローカルストレージに保存します。

## 機能

- 日付、競馬場、レース番号、レース名の入力
- コンピ順位1位〜10位の入力
- テクニカル6のパターンとメモの入力
- 階級指数、調教評価、朝イチ単勝順位、朝イチ複勝順位、馬連順位の入力
- 軸候補、相手候補、買い目メモの入力と保存済みメモ表示
- スマホ・タブレットで見やすい縦長レイアウト
- ブラウザ内保存（localStorage）

## 使い方

1. `index.html` をブラウザで開きます。
2. レース情報、コンピ順位、テクニカル6、補助指標、結論メモを入力します。
3. 「保存する」を押すと、ブラウザ内にデータが保存され、右下または下部の「保存済みメモ」に反映されます。
4. 「入力をクリア」を押すと、画面上の入力欄だけを空にできます。保存済みデータは削除されません。
5. 「保存データ削除」を押すと、ブラウザ内に保存されたデータも削除されます。
