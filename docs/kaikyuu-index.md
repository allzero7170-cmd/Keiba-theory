# 階級指数

## 概要

階級指数は、その馬の階級が高いかどうか、つまり「お買い得度合い」を数値で見るための指標。

```text
階級指数 = コンピ指数値 - 基準値
```

基準値は、出走頭数ごとの各コンピ順位における「上流階級」と「下流階級」の分かれラインとして扱う。便宜上、または経験上、若干の補正をかけて使う。

階級指数が高い場合は、該当馬の勝負度合いを上げる材料にする。

## 使い方

例：18頭立て・コンピ5位・コンピ指数60の場合

```text
基準値 = 56
階級指数 = 60 - 56 = +4
```

この場合、コンピ5位としては基準値を4上回るため、階級指数プラス馬として評価する。

## 運用メモ

- コンピ順位と出走頭数から基準値を決める。
- コンピ指数値から基準値を引く。
- プラス幅が大きいほど、その順位帯ではお買い得度が高いと見る。
- 画像表の白抜き・網掛け部分は、好走率と期待値のバランスが取れた特注ゾーンとして扱う。
