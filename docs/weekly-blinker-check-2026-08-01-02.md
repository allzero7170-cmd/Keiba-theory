「初ブリンカー」は今回が初着用と確認できた馬だけに付ける。過去に着用歴があり、間隔を空けて再び着用する馬は「再着用」、前走から続ける馬は「継続着用」と分ける。

## 改善判定

着用前後を最低でも次の観点で比較する。

1. 着順だけでなく、勝ち馬との着差が縮んだか。
2. 先行位置、道中位置、直線の反応など、着用目的に沿う変化があったか。
3. 距離、馬場、クラス、展開が大きく変わっていないか。
4. 一度だけの好走を「改善あり」と断定せず、可能なら複数走を確認する。

初着用馬は着用後実績が存在しないため「改善あり」にはしない。初着用という変化材料と、調教、枠、脚質、朝の売れ方を別々に記録する。

## コンピ順位・単勝オッズとの関連

アプリでは、各ブリンカー馬について次を自動表示する。

```text
コンピ順位 − 朝イチ単勝順位
```

- 正の値：コンピ評価より単勝が売れている。
- 0：同順位。
- 負の値：コンピ評価ほど単勝では売れていない。

特に「初着用または再着用」「コンピ6位以下」「朝イチ単勝3位以内」が重なる馬は、市場が変化材料を先に評価している可能性があるため注目欄で確認する。ただし、関連は因果関係ではなく、単勝オッズは発売中に変動する。時刻を固定して記録し、最終オッズとは分けて検証する。

## 仮配点

| 材料 | 点 |
|---|---:|
| 初着用 | +4 |
| 再着用 | +3 |
| 継続着用 | +1 |
| 過去の着用後に改善あり | +6 |
| 変化なし | -2 |
| 悪化 | -5 |

この点数は過去集計から得た回収率ではなく、記録と検証を始めるための仮説である。週末ごとに「該当頭数、勝率、複勝率、単勝回収率、複勝回収率」を着用区分×コンピ順位帯ごとに蓄積し、十分な標本ができるまで購入根拠にはしない。

## 更新手順

1. 確定出馬表からブリンカー表記のある馬を全場・全レースで抽出する。
2. 各馬の過去走を確認し、初着用・継続・再着用を分類する。
3. 着用前後の走りを比較し、改善、変化なし、悪化、未確認に分類する。
4. 同一時刻のコンピ順位、朝イチ単勝順位、単勝オッズを記録する。
5. レース後に結果と払戻を追記し、区分別の成績を集計する。
