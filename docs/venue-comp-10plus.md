# 会場別コンピ順位データ（出走10頭以上）

この資料は、出走10頭以上のレースについて、全競馬場合算と各競馬場のコンピ順位別成績を比較し、狙いやすい「会場×コンピ順位」を整理した基準資料である。

## 基本原則

- 「その順位が来やすいか」と「回収率が高いか」は分けて評価する。
- 単勝回収率だけが高く、複勝率が極端に低い順位は、少数の高配当に依存する大穴型として扱う。
- 実戦では、会場別の得意コンピ順位だけで決めず、次の材料との重なりを重視する。

```text
会場別の得意コンピ順位
＋階級指数
＋テクニカル6
＋調教加点
＋朝イチオッズ異常
```

## 実装・分析上の注意

- 会場加点だけで自動的に本命・買いとしない。
- 複勝率、単回収率、複回収率の3指標を併記する。
- 低頻度の大穴順位は、通常候補とは別枠表示する。
- 11位以下は原則イレギュラー扱いだが、会場特性と他の強い材料が重なった場合は例外候補にする。
- 将来データを追加した場合は、対象レース数と全体平均との差を再計算する。
